# 工单系统开发任务清单

**业主端报修工单基础模块 + 维修工端工单作业核心模块 + 物业端工单监管模块 + AI工单辅助赋能 + 工单AI智能处理引擎 + 工单AI智能复盘**，需要完成的全部具体要点如下：


## 一、业主端 · 报修工单基础模块

### 【增】
1. **提交报修单**：表单包含文字描述（必填）+ 图片上传（可选，最多9张）
2. **撤销报修申请**：仅限“待分配”状态且未被维修工接单的工单，撤销需二次弹窗确认
3. **电子签名确认**：维修完成后，业主在手写签名板上签字确认
4. **服务评价提交**：1-5星评分 + 标签多选（如“服务态度好”“技术专业”“速度慢”等）

### 【删】
1. **删除/撤销工单**：同上“撤销报修申请”，仅限特定状态

### 【查】
1. **实时查看工单状态**：待分配 / 处理中 / 待验收 / 已完成 / 已取消
2. **查看工单处理进度节点明细**：如已派单、维修工已出发、正在维修等
3. **查看被指派维修人员信息**：姓名、联系方式（虚拟号）、工号
4. **查看个人历史报修记录**：按时间倒序排列，支持按状态筛选

### 【改】
1. **补充报修信息**：在工单被接单前，支持补充文字描述或追加图片
2. **提交电子签名与评价**（见【增】第3、4条）


## 二、维修工端 · 工单作业核心模块

### 【增】
1. **维修现场拍照上传**：最多9张，每张图片**自动添加时间戳水印**

### 【查】
1. **接收系统派发工单推送通知**：APP弹窗 + 消息列表（使用轮询或列表刷新即可）
2. **查看工单详情**：故障描述、紧急等级、业主地址、业主联系电话、现场配图
3. **按日期/状态筛选个人历史维修工单**
4. **手动检索维修知识库**：按关键词查找常见故障解决方案（静态知识库匹配即可）

### 【改】
1. **手动设置个人忙闲状态**：可接单 / 忙线中 / 休息（用于AI派单依据）
2. **接单或拒单**：对系统推送的工单进行接单/拒单，拒单需从下拉选项选择理由
3. **实时更新工单状态**：待处理 → 处理中 → 已完成
4. **配合业主完成电子验收**：业主APP签字后，工单自动闭环


## 三、物业端 · 工单监管模块

### 【增】
1. **自定义报修类型**：支持多级分类（如“水电→水管漏水”）

### 【查】
1. **多维度筛选全量工单列表**：按状态、类型、紧急等级、时间段筛选
2. **查看单个工单全流程节点及操作时间轴**：包含操作人、操作时间、状态变更
3. **核验业主电子验收凭证**：查看签名图片

### 【改】
1. **人工干预工单——重新指派维修人员**：修改assignee字段，须填写原因
2. **手动调整工单状态**：如强制置为“已完成”，须填写原因
3. **修改工单紧急等级或故障类型**


## 四、AI工单辅助赋能（维修工端嵌入）

### 【查】
1. **智能匹配维修步骤方案**：根据故障类型（如“马桶堵塞”），推送标准维修步骤方案（静态模板匹配即可，无需调用大模型）


## 五、工单AI智能处理引擎（物业端后端能力）

### 【增】
1. **多模态自动归类故障类型**：识别报修文字+图片，自动归类（如“水管漏水”“电路跳闸”）
2. **智能划分紧急等级**：普通 / 较急 / 紧急（基于关键词+图片严重程度）
3. **自动标注高风险故障**：如漏电、燃气泄漏，工单置顶并高亮
4. **自动派单**：依据维修工技能标签、当前忙闲状态、地理位置进行智能派单

### 【查】
1. **智能识别重复报修**：同地址同类型近7天内重复报修，打标签提醒


## 六、工单AI智能复盘（物业端后端能力）

### 【增】
1. **每周一自动生成工单复盘周报**，包含以下数据：
   - 总工单数、平均完成时长
   - 超时率
   - 重复报修率
   - 好评率
   - 按故障类型/维修工统计平均处理时长
   - **基于数据生成优化建议**（如“建议增加夜间维修班次”——调用大模型生成）
2. **生成月度服务质量趋势图**：评价得分曲线、超时率变化
