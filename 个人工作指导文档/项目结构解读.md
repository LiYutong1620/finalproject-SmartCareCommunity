## 项目总览

**Smart Care Community（智慧社区）** 是一个前后端分离的社区管理平台，当前仓库主要覆盖以下业务：
- 住户资源管理
- 报修工单管理
- 社区公告通知
- 老人关怀
- AI 问答与知识库
- 系统登录、用户与配置管理

**技术栈：**
- 后端：Spring Boot 3.2 + Spring Security + JWT + MyBatis-Plus + MySQL 8
- 前端：Vue 3 + Vite + Pinia + Element Plus
- AI：智谱相关客户端与 RAG 能力（用于社区 AI 问答与知识库）

### 8. 后端当前可确认的报修能力

- 业主提交报修时支持文字描述与多图上传
- 业主可撤销“待分配”且未被接单的工单
- 业主可查看工单详情与处理进度
- 维修工可接单、更新状态、完工
- 业主可进行验收签名与评价
- 物业可查看工单列表并执行派单

## 四、当前结构解读结论

1. 项目已经具备完整的基础分层：数据库、后端业务、前端页面、路由与 API 分离明确。
2. 报修工单模块是当前最完整的业务闭环，且已扩展到图片、签名、评价、进度展示等能力。
3. 任务清单中原先写入的部分规划性内容，当前仓库并未实现或未形成对应页面/接口，不能再当作“已完成结构”描述。
4. 后续新增功能时，建议继续按“后端实体/Mapper/Service/Controller + 前端页面/API/路由”的方式补齐。
